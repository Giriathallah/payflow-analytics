B. KONTEKS PENELITIAN YANG HARUS DIPERTAHANKAN
==================================================

Penelitian ini memiliki konteks sebagai berikut:

1. Penelitian mengembangkan prototipe sistem skrining dini disleksia berbasis web.

2. Sistem mendeteksi pola tulisan tangan menggunakan YOLOv11m.

3. Model mendeteksi dan mengklasifikasikan objek ke dalam tiga kelas:
   - Normal;
   - Reversal;
   - Corrected.

4. Dataset berasal dari:
   - Synthetic Dyslexia Handwriting Dataset dari Zenodo;
   - Dyslexia Handwriting Dataset dari Kaggle.

5. Dataset Kaggle awalnya berupa citra huruf tunggal, kemudian dikonversi menjadi citra sintetis multiobjek beserta anotasi bounding box berformat YOLO.

6. Pengembangan model mengikuti CRISP-DM.

7. Pengembangan aplikasi mengikuti SDLC model Waterfall.

8. Model dilatih dengan ukuran citra 416 × 416 piksel.

9. Evaluasi model menggunakan:
   - Precision;
   - Recall;
   - F1-Score;
   - mAP@0.5;
   - mAP@0.5:0.95.

10. Model diekspor ke format ONNX.

11. Aplikasi menggunakan:
    - Next.js dan TypeScript pada frontend;
    - FastAPI pada backend;
    - ONNX Runtime untuk inferensi;
    - Vercel sebagai platform deployment.

12. Frontend dan backend di-deploy sebagai project Vercel yang terpisah.

13. Evaluasi model dilakukan pada validation set internal.

14. Penelitian belum menggunakan independent test set berdasarkan penulis atau sumber data.

15. Generalisasi model terhadap tulisan tangan nyata belum dapat dipastikan.

16. Sistem merupakan prototipe alat bantu skrining awal, bukan alat diagnosis medis atau klinis.

17. Pengujian fungsional dilakukan menggunakan black box testing pada lingkungan production.

Jangan mengubah konteks tersebut dan jangan menambahkan metode, eksperimen, dataset, pengujian, atau fitur yang tidak dilakukan dalam penelitian.

D. TINGKAT PRIORITAS TEMUAN
==================================================

Klasifikasikan temuan sebagai berikut:

### KRITIS

Masalah yang berpotensi memengaruhi validitas penelitian, misalnya:

- data leakage;
- metode evaluasi yang tidak tepat;
- angka hasil tidak konsisten;
- rumusan masalah tidak terjawab;
- kesimpulan tidak didukung hasil;

- validation set disebut sebagai independent test set;
- eksperimen yang tidak dapat direproduksi;
- penggunaan referensi yang tidak mendukung klaim utama.

### MAYOR

Masalah yang mengurangi kualitas akademik, misalnya:

- argumentasi research gap lemah;
- metode kurang rinci;
- pembahasan hanya mendeskripsikan tabel;
- istilah teknis tidak konsisten;
- hubungan antara metode dan hasil tidak jelas;
- kontribusi penelitian tidak tegas;
- keterbatasan tidak dibahas;
- penjelasan teknis tidak sesuai implementasi.

### MINOR

Masalah yang tidak mengubah validitas penelitian, misalnya:

- typo;
- kalimat tidak efektif;
- pengulangan;
- kapitalisasi;
- tanda baca;
- penulisan istilah asing;
- pemilihan kata;
- format angka atau singkatan.

Jangan mengklasifikasikan typo atau format sebagai masalah kritis.

14. Apabila suatu klaim tidak dapat dipertahankan, revisi klaim tersebut agar sesuai dengan penelitian yang benar-benar dilakukan.

15. Apabila suatu bagian membutuhkan eksperimen tambahan, jangan berpura-pura eksperimen tersebut telah dilakukan. Tandai sebagai keterbatasan atau saran penelitian selanjutnya.
